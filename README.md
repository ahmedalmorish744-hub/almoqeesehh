# منصة إصدار تقرير الإجازة المرضية — Vercel (Next.js + Vercel Postgres)

تطبيق Next.js 16 يعمل **بالكامل على Vercel** — لا اعتماد على Railway أو أي خدمة خارجية.
يحل محل بوت Telegram القديم بصفحة ويب لإدخال بيانات الإجازة المرضية، يطبع تقرير PDF
ويحفظ البيانات في قاعدة بيانات Vercel Postgres في نفس اللحظة.

## الميزات

- ✅ **صفحة إدخال بيانات كاملة** — 16 حقلاً موزّعة على 4 مجموعات (المريض، الإجازة، الطبيب، المنشأة)
- ✅ **صندوق اللصق الذكي** — الصق رسالة البوت القديمة (بالرموز 👤 🆔 🌍 🏢 👨‍⚕️ 💼 📅 🏥 🔢 ⏰)
  وستُملأ الحقول تلقائياً
- ✅ **زر واحد للطباعة + الحفظ** — يولّد ملف PDF ويفتحه للطباعة، ويحفظ البيانات في Vercel Postgres
- ✅ **تبويب الاستعلام** — ابحث عن الإجازات السابقة برمز GSL أو رقم الهوية أو نص حر،
  وحمّل أي سجل في النموذج لتعديله أو إعادة طباعته
- ✅ **تقرير PDF احترافي** — بنفس تصميم البوت الأصلي مع إصلاح أخطاء الأقواس المقلوبة وتوحيد الخطوط
- ✅ **حفظ مسودة محلياً** (localStorage) لاسترجاع البيانات بين الجلسات
- ✅ **Vercel-only** — كل البيانات والملفات والـ API على Vercel، لا حاجة لأي خدمة خارجية

## النشر على Vercel (5 خطوات)

### 1. ارفع المستودع إلى GitHub
```bash
git init
git add .
git commit -m "Sick leave web app — Vercel only"
git branch -M main
git remote add origin https://github.com/<your-user>/<your-repo>.git
git push -u origin main
```

### 2. اربط المستودع بـ Vercel
1. اذهب إلى https://vercel.com/new
2. اختر المستودع
3. الإعدادات الافتراضية تعمل (Next.js يُكتشف تلقائياً)
4. **لا تضف متغيرات بيئة يدوياً بعد** — اضغط Deploy أولاً

### 3. أنشئ قاعدة بيانات Vercel Postgres
1. في صفحة المشروع على Vercel: اذهب إلى **Storage** → **Create Database**
2. اختر **Postgres** (فئة Free كافية)
3. أعطِها اسماً (مثل `seha-leaves-db`) واضغط **Create**
4. اربطها بالمشروع: **Connect Project** → اختر مشروعك → **Env Variables** ستنشأ تلقائياً
   - `POSTGRES_URL`, `POSTGRES_URL_NON_POOLING`, `POSTGRES_USER`,
     `POSTGRES_HOST`, `POSTGRES_PASSWORD`, `POSTGRES_DATABASE`

### 4. أنشئ الجداول (مرة واحدة فقط)
طريقة أسهل — من Vercel Dashboard:
1. اذهب إلى **Storage** → قاعدة البيانات → **Query** tab
2. افتح ملف `schema.sql` من هذا المستودع، انسخ كامل محتواه
3. الصقه في محرر الـ SQL في Vercel واضغط **Run**
4. سترى رسالة نجاح — الجداول الخمسة أُنشئت (`users`, `nationalities`,
   `hospitals`, `doctors`, `sick_leaves`)

أو من سطر الأوامر (بعد ضبط متغيرات البيئة محلياً):
```bash
bun run db:init
```

### 5. أعد النشر (Redeploy)
في Vercel Dashboard → مشروعك → **Deployments** → أحدث deployment → **⋯** → **Redeploy**
الآن التطبيق سيكون قادراً على حفظ البيانات والبحث فيها.

## التطوير محلياً

```bash
bun install
bun run dev      # http://localhost:3000
bun run lint     # فحص الكود
bun run db:init  # تهيئة قاعدة البيانات (يتطلب POSTGRES_URL)
```

ملاحظة: محلياً سيعمل توليد PDF حتى بدون قاعدة بيانات. أما الحفظ والاستعلام
فسيُرجعان رسالة واضحة "قاعدة بيانات Vercel Postgres غير مربوطة".

## إصلاحات PDF في هذه النسخة

- ✅ **أقواس مقلوبة** — استبدلنا الأقواس اللاتينية `()` بالأقواس العربية العريضة `（）`
  في السياق العربي لمدة الإجازة، فتظهر بشكل صحيح في اتجاه RTL
- ✅ **نقطتان بعد "رقم الترخيص"** — استخدمنا النقطتين العربيتين `：` لعرضهما في الموضع الصحيح
- ✅ **توحيد الخطوط** — كل النصوص العربية بخط Noto Sans Arabic، والإنجليزية بخط Times
- ✅ **عرض التواريخ** — التواريخ في عمود القيمة تُعرض بخط Times لتفادي أي علامات استفهام
