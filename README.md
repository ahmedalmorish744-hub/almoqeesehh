# منصة إصدار تقرير الإجازة المرضية — Vercel

تطبيق Next.js 16 يحل محل بوت Telegram القديم بصفحة ويب لإدخال بيانات
الإجازة المرضية. يطبع تقرير PDF ويرفع البيانات إلى خادم منصة صحة في نفس اللحظة.

## الميزات

- **صفحة إدخال بيانات كاملة** (16 حقلاً موزّعة على 4 مجموعات: المريض، الإجازة، الطبيب، المنشأة).
- **صندوق اللصق الذكي**: الصق رسالة البوت القديمة (بنفس الصيغة التي تحتوي على الرموز 👤 🆔 🌍 🏢 👨‍⚕️ 💼 📅 🏥 🔢 ⏰)
  وستُملأ الحقول تلقائياً.
- **زر واحد للطباعة والرفع**: يولّد ملف PDF ويفتحه للطباعة، ويرفع البيانات إلى الخادم في نفس اللحظة.
- **تقرير PDF احترافي** بنفس تصميم البوت الأصلي: شعار صحة، شعار المملكة، رمز QR، جدول ثلاثي الأعمدة (عربي/قيمة/إنجليزي).
- **حفظ مسودة محلياً** (localStorage) لاسترجاع البيانات بين الجلسات.

## النشر على Vercel

### 1. ارفع المستودع إلى GitHub
```bash
git init
git add .
git commit -m "Sick leave web app"
git branch -M main
git remote add origin https://github.com/<your-user>/<your-repo>.git
git push -u origin main
```

### 2. اربط المستودع بـ Vercel
1. اذهب إلى https://vercel.com/new
2. اختر المستودع
3. الإعدادات الافتراضية تعمل (Next.js يُكتشف تلقائياً)
4. أضف متغيرات البيئة (Environment Variables):

| المتغير | القيمة الافتراضية | الوصف |
|---------|------------------|-------|
| `API_BASE_URL` | `https://alehtiat-almorish-production.up.railway.app` | عنوان خادم API الخلفي |
| `API_ENDPOINT` | `/api/bot/add_leave` | مسار نقطة نهاية الإضافة |
| `BOT_API_KEY` | `seha_bot_secret_key_2025` | مفتاح API للتصديق |

5. اضغط Deploy

### 3. تأكد من أن خادم Railway يعمل
الخادم الخلفي على Railway يجب أن يكون قيد التشغيل ويستقبل طلبات POST على
`/api/bot/add_leave` بمفتاح API المتفق عليه. إذا كان متوقفاً، ستفشل عملية
الرفع بينما تنجح الطباعة (لا تزال تستطيع استخدام الـ PDF).

## التطوير محلياً

```bash
bun install
bun run dev   # http://localhost:3000
```

## بنية المشروع

```
src/
├── app/
│   ├── layout.tsx                  # تخطيط RTL عربي مع خط Cairo

├── fonts/                          # خطوط Noto Sans Arabic (Regular + Bold)
└── images/                         # شعار صحة + المملكة + المركز الوطني + شعار هندسي
```
